# Assignment 3 — Mobile Computing (CO3)

This folder contains a separate Python demonstration for each of the seven assignment questions, a matching text output, and a terminal-style SVG output image.

## Questions
1. Wireless network architecture and mobility / handoff
2. Mobile IP registration, packet delivery and tunnelling
3. Cellular versus ad hoc network connectivity
4. Mobile IP application: mobile healthcare
5. Proactive routing: DSDV table updates
6. Reactive routing: AODV and DSDV comparison
7. Mobile emergency communication network design and validation

## Run
Open a question folder and run:
```bash
python main.py
```

## Academic note
These are small educational models to demonstrate the concepts. Any values labelled illustrative are not measurements from a real wireless network or a packet-level simulator. Assignment 3 is pair work: retain both students' independent design proposals, discuss the joint decisions, and be prepared to explain all questions during viva. The supplied assignment also requires language-independent pseudocode for mobile-network algorithms; Python code here is supporting demonstration, not a replacement for that pseudocode.
