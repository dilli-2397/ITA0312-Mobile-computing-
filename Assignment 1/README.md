# Assignment 1 — Mobile Computing (CO1)

Design, Analyse and Optimise a Hexagonal Cellular Network for a University Township.

This folder contains 12 task/question subfolders. Each subfolder contains:
- `main.py` — compact Python calculation, model or analysis helper.
- `output.txt` — representative output / interpretation.
- `output_screenshot.svg` — terminal-style output illustration.

Run any task using `python main.py` from its folder.

Planning assumptions used in the supplied CO1 report: 12 km² township, 336 duplex channels, N=7 baseline, R=0.5 km, n=3.5, 14 dB SIR target, 0.025 Erlang per subscriber and 2% blocking target.

Important: The SVG files are illustrative output captures generated from the expected results, not screenshots of a live terminal. Run the Python files and replace them with genuine screenshots if required by your faculty. The Monte Carlo / field-measurement portions require actual simulation extensions or survey data; scripts do not fabricate measured results. Review the assignment sheet and personalise assumptions and explanations before submission.
