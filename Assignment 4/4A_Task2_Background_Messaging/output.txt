4A TASK 2 - CROSS-PLATFORM BACKGROUND MESSAGING
Android: Linux; Binder; ART; FCM; Doze; per-app UID sandbox
iOS: XNU; Mach/XPC; native Swift/Obj-C; APNs; strict background policy
Windows: Windows NT; WinRT/COM; CLR or native; push/background task policy
Incoming message: push service -> OS policy -> notification/eligible callback -> encrypted local persistence
Killed process: visible push may still appear; silent callback is not guaranteed.
Design: server-side durable queue + authenticated fetch + idempotent message ID + encrypted storage.
