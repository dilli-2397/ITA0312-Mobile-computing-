# Assignment 2 — Mobile Computing (CO2)

This folder contains one Python simulation per question, the captured console output, and an output screenshot for each question.

## Structure
- Q1_Store_and_Forward
- Q2_FDMA_TDMA
- Q3_CDMA
- Q4_OFDMA
- Q5_SDMA
- Q6_Technique_Selection
- Q7_Shared_Pool_Redesign

## Run
Open a question folder and run:
```bash
python main.py
```

The scripts use fixed random seeds where applicable. Results are illustrative outputs from simplified educational models, not measurements from a real cellular network. Review the assumptions in each script and in the uploaded assignment report before submission.
