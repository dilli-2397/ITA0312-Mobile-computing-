# Assignment 4 — Mobile Computing (CO4)

Organised into Assignment 4A (Part I) and Assignment 4B (Part II), with six task folders under each part.

Each task folder contains:
- `main.py` — a small Python model, checklist or evidence helper
- `output.txt` — output or evidence guidance
- `output_screenshot.svg` — terminal-style output illustration

Run a script with `python main.py`.

Important: Assignment 4B requires actual Android device/emulator evidence (adb, Profiler/Perfetto, ART/GC and battery tools). The scripts provide commands and reproducible policy demonstrations; they do not fabricate measurements from your phone. Replace guidance output with your own device logs and screenshots before submission. Assignment 4A is primarily architectural design and structured analysis, so Python files support—but do not replace—the required tables, traces and written design.
